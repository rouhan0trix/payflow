How PayFlow Enforces Payment Correctness

🔒

Idempotency Engine

Prevents double charges when users double-click or network connections retry. Exact duplicates return the original payment (HTTP 200); payload mismatches with reused keys return HTTP 409 Conflict.

💰

Integer Paise Arithmetic

Financial software never uses floating-point numbers. Amounts are strictly validated and stored as positive integer minor units (100 paise = ₹1.00) to eliminate IEEE 754 rounding errors.

⚡

ACID Refund Transactions

Refunds require updating the payment state, creating a refund record, and logging an audit history entry. All writes execute inside a single atomic SQLite transaction with automatic rollback on error.
